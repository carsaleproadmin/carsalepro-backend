## health

Liveness + dependency probe

### `GET /health`

*Liveness + dependencies probe*

**Responses**

**200** — The Health Check is successful

```json
{
  status: string, // e.g. "ok"
  info: object, // e.g. {"database":{"status":"up"}}
  error: object, // e.g. {}
  details: object, // e.g. {"database":{"status":"up"}}
}
```

**503** — The Health Check is not successful

```json
{
  status: string, // e.g. "error"
  info: object, // e.g. {"database":{"status":"up"}}
  error: object, // e.g. {"redis":{"status":"down","message":"Could not connect"}}
  details: object, // e.g. {"database":{"status":"up"},"redis":{"status":"down","message":"Could not connect"}}
}
```

## vin

NHTSA vPIC decoder with Postgres cache

### `GET /vin/{vin}`

*Decode a VIN via NHTSA vPIC with Postgres cache*

Cache-first lookup. On miss, fetches from vpic.nhtsa.dot.gov and stores the result. Returns 404 when NHTSA has no meaningful data for the VIN (mobile app must allow manual entry).

**Parameters**

| Name | In | Required | Type | Description |
|---|---|---|---|---|
| vin | path | **yes** | string | 17-char VIN |

**Responses**

**200** — 

```json
{
  "vin": "1HGBH41JXMN109186",
  "make": "HONDA",
  "model": "Accord",
  "modelYear": 2021,
  "plantCountry": "JAPAN",
  "bodyClass": "Sedan/Saloon",
  "fuelType": "GASOLINE",
  "source": "nhtsa-vpic",
  "cached": true,
  "raw": {}
}
```

### `POST /quota/upgrade`

*Mark device as PRO after IAP success*

`IAP_VALIDATION_MODE` selects the mode.

- `server`: the API sends the purchase to the store before it gives PRO. iOS: send the StoreKit 2 signed transaction (JWS). The API gets the transaction from the App Store Server API, and checks the bundle id, the product id `carsalepro_pro_lifetime` and the revocation date. Android: send the purchase token and `productId`. The API calls `purchases.products.get`, checks `purchaseState`, and acknowledges the purchase.
- `client-trust`: the API gives PRO for each request, also for a fake receipt.

If the store does not confirm the purchase, the device does not get PRO. One purchase gives PRO to 5 devices at most. Each error body has a `code`.

> The env vars and the procedure to switch to `server` mode are in the [README](../README.md#mobile-pro-purchase-validation).

**Parameters**

| Name | In | Required | Type | Description |
|---|---|---|---|---|
| X-Device-Id | header | **yes** | string | UUID v4 generated by the mobile client. Persistent per install. |

**Request body**

```json
{
  "platform": "ios",
  "receipt": "eyJhbGciOiJFUzI1NiIsIng1YyI6WyJNSUlF...",
  "productId": "carsalepro_pro_lifetime",
  "environment": "string"
}
```

`receipt` is `PurchaseDetails.verificationData.serverVerificationData`. iOS: the StoreKit 2 signed transaction (JWS). A bare numeric transaction id is refused. A base64 StoreKit 1 app receipt is accepted only when `APPLE_SHARED_SECRET` is set. Android: the purchase token.

**Responses**

**200** —

```json
{
  "deviceId": "b2f24f8e-3b6f-4f3e-8ad4-5e5d2f3a1c40",
  "freeReportsUsed": 1,
  "freeReportsLimit": 3,
  "isPro": false,
  "remaining": 2
}
```

**400** — The store or the request rejects the purchase. Body: `{ error: "IapValidationFailed", code, message, providerCode }`.

**409** — The purchase already gives PRO to 5 other devices. Body: `{ error: "IapDeviceLimit", code: "iap_device_limit", message, deviceLimit }`. A device that already has the purchase does not get this error.

**503** — The API cannot get a decision from the store (outage, or credentials not set). Try again later. Body: `{ error: { code, message }, code, message, providerCode }`.

| Status | `code` | Meaning |
|---|---|---|
| 400 | `iap_receipt_empty` | The `receipt` is empty. |
| 400 | `iap_receipt_malformed` | The JWS payload has no numeric `transactionId`. |
| 400 | `iap_receipt_unsupported` | A bare numeric transaction id, or a StoreKit 1 app receipt when `APPLE_SHARED_SECRET` is not set. |
| 400 | `iap_product_id_required` | Android request without `productId`. |
| 400 | `iap_bundle_mismatch` | The purchase is for a different app. |
| 400 | `iap_product_mismatch` | The purchase is not `carsalepro_pro_lifetime`. |
| 400 | `iap_purchase_revoked` | The store refunded or revoked the purchase. |
| 400 | `iap_purchase_not_completed` | Google `purchaseState` is not 0 (pending or cancelled). |
| 400 | `iap_transaction_not_found` | Apple has no such transaction in production or in the sandbox. |
| 400 | `iap_store_rejected` | The store rejects the receipt or the token. |
| 400 | `iap_platform_unsupported` | The platform is not `ios` or `android`. |
| 409 | `iap_device_limit` | The purchase already gives PRO to 5 other devices. |
| 503 | `iap_not_configured` | Server mode is on, but the store credentials are not set. |
| 503 | `iap_store_auth_failed` | The store rejects the server credentials. |
| 503 | `iap_store_unavailable` | Timeout, network error, 429, 5xx, or an Apple "retry later" error (for example 4040004). |

---|---|---|---|---|
| X-Device-Id | header | **yes** | string | UUID v4 generated by the mobile client. Persistent per install. |

**Request body**

```json
{
  "platform": "ios",
  "receipt": "MIIBoAYJKoZIhvcNAQcC...",
  "productId": "carsalepro_pro_lifetime",
  "environment": "string"
}
```

**Responses**

**200** — 

```json
{
  "deviceId": "b2f24f8e-3b6f-4f3e-8ad4-5e5d2f3a1c40",
  "freeReportsUsed": 1,
  "freeReportsLimit": 3,
  "isPro": false,
  "remaining": 2
}
```

### `POST /reports`

*Reserve a report and obtain a presigned R2 upload URL*

Atomically checks the FREE-tier quota (3 reports lifetime). PRO devices have no limit. On quota exhaustion returns 402 Payment Required and does NOT create a report row.

**Parameters**

| Name | In | Required | Type | Description |
|---|---|---|---|---|
| X-Device-Id | header | **yes** | string | UUID v4 generated by the mobile client. Persistent per install. |

**Request body**

```json
{
  "code": "CSP-042",
  "vin": "1HGBH41JXMN109186",
  "sizeBytes": 1834217,
  "hash": "7f83b1657ff1fc53b92dc18148a1d65dfc2d4b1fa3d677284addd200126d9069",
  "contentType": "application/pdf"
}
```

**Responses**

**200** — 

```json
{
  "reportId": "ckqz2zk5e0000a8b8h4t8j2z3",
  "s3Key": "free/<deviceId>/<reportId>.pdf",
  "presignedUploadUrl": "https://<account>.r2.cloudflarestorage.com/carsalepro-reports/free/.../...pdf?X-Amz-Signature=...",
  "expiresAt": "2026-05-15T17:42:00.000Z",
  "tier": "free"
}
```

**402** — FREE-tier limit reached

```json
{
  "statusCode": 400,
  "error": "BadRequestException",
  "message": "X-Device-Id header is required",
  "path": "/reports",
  "timestamp": "2026-05-15T17:42:00.000Z"
}
```

## me

Per-device account operations (GDPR erasure)

### `DELETE /me`

*GDPR right-to-erasure for this device*

Removes all DB rows (reports + quota) and every R2 object stored for this deviceId. Irreversible.

**Parameters**

| Name | In | Required | Type | Description |
|---|---|---|---|---|
| X-Device-Id | header | **yes** | string | UUID v4 of the device requesting erasure. |

**Responses**

**200** — 

```json
{
  "deviceId": "b2f24f8e-3b6f-4f3e-8ad4-5e5d2f3a1c40",
  "reportsDeleted": 3,
  "objectsDeleted": 3,
  "quotaDeleted": true
}
```
