## health

Liveness + dependency probe

### `GET /health`

*Liveness + dependencies probe*

**Responses**

**200** — The Health Check is successful

```json
{
  status: string, // e.g. "ok"
  info: object, // e.g. {"database":{"status":"up"}}
  error: object, // e.g. {}
  details: object, // e.g. {"database":{"status":"up"}}
}
```

**503** — The Health Check is not successful

```json
{
  status: string, // e.g. "error"
  info: object, // e.g. {"database":{"status":"up"}}
  error: object, // e.g. {"redis":{"status":"down","message":"Could not connect"}}
  details: object, // e.g. {"database":{"status":"up"},"redis":{"status":"down","message":"Could not connect"}}
}
```

## vin

NHTSA vPIC decoder with Postgres cache

### `GET /vin/{vin}`

*Decode a VIN via NHTSA vPIC with Postgres cache*

Cache-first lookup. On miss, fetches from vpic.nhtsa.dot.gov and stores the result. Returns 404 when NHTSA has no meaningful data for the VIN (mobile app must allow manual entry).

**Parameters**

| Name | In | Required | Type | Description |
|---|---|---|---|---|
| vin | path | **yes** | string | 17-char VIN |

**Responses**

**200** — 

```json
{
  "vin": "1HGBH41JXMN109186",
  "make": "HONDA",
  "model": "Accord",
  "modelYear": 2021,
  "plantCountry": "JAPAN",
  "bodyClass": "Sedan/Saloon",
  "fuelType": "GASOLINE",
  "source": "nhtsa-vpic",
  "cached": true,
  "raw": {}
}
```

---

### `POST /quota/upgrade`

*Mark device as PRO after IAP success*

When `IAP_VALIDATION_MODE=server` (Render env), the receipt is validated against Apple's App Store servers or Google Play Developer API before the device is upgraded. If validation fails the request returns 400 with the provider error code. In `client-trust` mode the call upgrades the device unconditionally (used in MVP launch).

**Parameters**

| Name | In | Required | Type | Description |
|---|---|---|---|---|
| X-Device-Id | header | **yes** | string | UUID v4 generated by the mobile client. Persistent per install. |

**Request body**

```json
{
  "platform": "ios",
  "receipt": "MIIBoAYJKoZIhvcNAQcC...",
  "productId": "carsalepro_pro_lifetime",
  "environment": "string"
}
```

**Responses**

**200** — 

```json
{
  "deviceId": "b2f24f8e-3b6f-4f3e-8ad4-5e5d2f3a1c40",
  "freeReportsUsed": 1,
  "freeReportsLimit": 3,
  "isPro": false,
  "remaining": 2
}
```

### `POST /reports`

*Reserve a report and obtain a presigned R2 upload URL*

Atomically checks the FREE-tier quota (3 reports lifetime). PRO devices have no limit. On quota exhaustion returns 402 Payment Required and does NOT create a report row.

**Parameters**

| Name | In | Required | Type | Description |
|---|---|---|---|---|
| X-Device-Id | header | **yes** | string | UUID v4 generated by the mobile client. Persistent per install. |

**Request body**

```json
{
  "code": "CSP-042",
  "vin": "1HGBH41JXMN109186",
  "sizeBytes": 1834217,
  "hash": "7f83b1657ff1fc53b92dc18148a1d65dfc2d4b1fa3d677284addd200126d9069",
  "contentType": "application/pdf"
}
```

**Responses**

**200** — 

```json
{
  "reportId": "ckqz2zk5e0000a8b8h4t8j2z3",
  "s3Key": "free/<deviceId>/<reportId>.pdf",
  "presignedUploadUrl": "https://<account>.r2.cloudflarestorage.com/carsalepro-reports/free/.../...pdf?X-Amz-Signature=...",
  "expiresAt": "2026-05-15T17:42:00.000Z",
  "tier": "free"
}
```

**402** — FREE-tier limit reached

```json
{
  "statusCode": 400,
  "error": "BadRequestException",
  "message": "X-Device-Id header is required",
  "path": "/reports",
  "timestamp": "2026-05-15T17:42:00.000Z"
}
```

---

### `POST /reports/{id}/complete`

*Confirm the PDF was successfully uploaded to R2*

Verifies the object exists in R2 and marks the report as uploaded. Reports that never complete remain in the device history but cannot be downloaded.

**Parameters**

| Name | In | Required | Type | Description |
|---|---|---|---|---|
| X-Device-Id | header | **yes** | string | UUID v4 generated by the mobile client. Persistent per install. |
| id | path | **yes** | string |  |

**Responses**

**200** — 

```json
{
  "id": "ckqz2zk5e0000a8b8h4t8j2z3",
  "uploaded": true
}
```

## me

Per-device account operations (GDPR erasure)

### `DELETE /me`

*GDPR right-to-erasure for this device*

Removes all DB rows (reports + quota) and every R2 object stored for this deviceId. Irreversible.

**Parameters**

| Name | In | Required | Type | Description |
|---|---|---|---|---|
| X-Device-Id | header | **yes** | string | UUID v4 of the device requesting erasure. |

**Responses**

**200** — 

```json
{
  "deviceId": "b2f24f8e-3b6f-4f3e-8ad4-5e5d2f3a1c40",
  "reportsDeleted": 3,
  "objectsDeleted": 3,
  "quotaDeleted": true
}
```
